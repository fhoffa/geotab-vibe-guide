# Geotab Vibe Coding Challenge 2026 — Project Directory

47 teams. 3 weeks. $25,000. February 12 – March 2, 2026.

All projects were built in the open. Browse the repos, watch the videos, learn and collaborate.

## Safety, Coaching & Driver Behavior

**FleetShield AI** 🏆 — [github.com/klickgenai/geotab-hackathon](https://github.com/klickgenai/geotab-hackathon)

Voice AI operator assistant + autonomous mission orchestration. The operator asks Tasha to run a coaching sweep — the system scores every driver against their 90-day baseline, updates their portal, and places real Twilio phone calls to flagged drivers. 17 Claude agent tools, 9 insurance/safety scoring engines, 736-line CLAUDE.md. [Winner interview](https://www.youtube.com/watch?v=G3A8PjtovN8)

---

**ClearSkies** — [github.com/reubenfrith/clearskies](https://github.com/reubenfrith/clearskies)

Weather-aware OSHA work-hold system for construction fleets. Knows exactly which vehicles are on each site when a storm hits, issues holds, and generates audit-ready compliance records. Solves a $5B/year problem in US construction.

---

**fleet-voice-alerts** — [github.com/pmetis/fleet-voice-alerts](https://github.com/pmetis/fleet-voice-alerts)

Detects fleet exceptions, enriches them with ACE, and calls supervisors directly via Twilio — the supervisor can ask follow-up questions by voice. Built for remote Latin American fleet operations where voice still reaches when data connectivity doesn't.

---

**GeoSafe** — [github.com/ribbeon/public-2026-geotab](https://github.com/ribbeon/public-2026-geotab)

Geofence intelligence platform. AI suggests zone boundaries based on where vehicles actually stop, combined with a conversational assistant for fleet queries.

---

**GEOPulse** — [github.com/crypticsaiyan/GEOPulse](https://github.com/crypticsaiyan/GEOPulse)

Behavioral fingerprinting with 3-channel output — compares each driver's patterns against their own baseline, the fleet baseline, and peer clusters simultaneously.

---

**Geoff** — [github.com/robertlagrasse/geotab-geoff](https://github.com/robertlagrasse/geotab-geoff)

Lip-synced AI avatar that delivers personalized per-shift driver coaching based on real trip and safety event data.

---

**Sentinel Fleet IA** — [github.com/JESUSMIJARES/geotab_vibe_coding_sentinel_fleet_ia](https://github.com/JESUSMIJARES/geotab_vibe_coding_sentinel_fleet_ia)

Multi-agent safety audit system integrating SmarterAI dashcam footage with Geotab telematics events.

---

**Ready to Roll** — [github.com/Bandoozle/geotab-vibecode](https://github.com/Bandoozle/geotab-vibecode)

Pre-trip driver readiness scoring.

---

**Fleet Whisperer** — [github.com/gprakashthoughtline/GeoTab](https://github.com/gprakashthoughtline/GeoTab)

## Developer Tools, SDKs & Platform Infrastructure

**FuelGuard MCP** — [github.com/mranna/fuelguard-mcp](https://github.com/mranna/fuelguard-mcp)

MCP server that detects fuel theft using graph clustering — finds vehicles losing fuel faster than expected across similar trip profiles.

---

**Attrix vibe challenge** — [github.com/attrix-technologies/vibe-challenge-entry](https://github.com/attrix-technologies/vibe-challenge-entry)

Built by Attrix, a Geotab reseller since 2015. They first used AI to build their own Add-In scaffolding tooling, then built "Last Week in Fleet" — a four-tab weekly fleet summary across productivity, safety, compliance, and sustainability. [Video](https://www.youtube.com/watch?v=EiZsIof1Scw)

---

**ActionEngine add-in** — [github.com/ActionEngine/geotab-add-in](https://github.com/ActionEngine/geotab-add-in)

6-algorithm GPS data quality validator — identifies coordinate drift, signal gaps, and anomalous trip artifacts that silently corrupt fleet analytics.

**mg-api-php** — [github.com/moxtheox/mg-api-php](https://github.com/moxtheox/mg-api-php)

Async PHP SDK using PHP 8.1 Fibers with full ACE integration — fills a real gap for PHP-heavy fleet tech stacks.

**Check-Fleet Onboarding** — [github.com/amufti-cmd/geotab-check-fleet-onboarding-agent](https://github.com/amufti-cmd/geotab-check-fleet-onboarding-agent)
